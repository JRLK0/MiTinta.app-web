Política de privacidad de Lorcana Lector

Fecha de entrada en vigor: 20 de agosto de 2026

Responsable: Jorge Megía. Contacto de privacidad: jorgemegia96@gmail.com.

Resumen

Lorcana Lector requiere una cuenta para sincronizar la colección entre Android y la web. No contiene publicidad ni vende información personal. Las imágenes de la cámara se procesan en memoria en el dispositivo para reconocer cartas y no son guardadas ni enviadas por la aplicación.

Datos y permisos

  • Cámara: se utiliza únicamente cuando el usuario abre el escáner. Las imágenes y el texto reconocido permanecen en el dispositivo.
  • Cuenta: se trata el correo electrónico, el identificador interno de usuario y la información técnica necesaria para autenticar y proteger el acceso.
  • Colección: cartas, cantidades, idioma y acabado se almacenan localmente y en PostgreSQL para sincronizarlas entre dispositivos. La copia automática de Android está desactivada.
  • Archivos CSV: la aplicación solo lee o escribe el archivo que el usuario selecciona expresamente mediante el selector de Android.
  • Internet: se usa para descargar catálogo, imágenes y precios. Los servidores que reciben la solicitud pueden recibir datos técnicos necesarios para la conexión, como la dirección IP.

Servicios de terceros

  • ML Kit de Google: realiza el reconocimiento de texto en el dispositivo. No envía a Google las imágenes, el texto reconocido ni los resultados. El SDK sí recopila información de la aplicación y el dispositivo, un identificador de instalación, eventos de uso, errores y métricas de rendimiento para diagnóstico, mantenimiento y mejora. Estos datos se cifran en tránsito y Google indica que no se comparten con terceros.
  • Lorcast: proporciona metadatos e imágenes públicas del catálogo.
  • Cardmarket/S3: proporciona archivos públicos de productos y precios.
  • Supabase: presta autenticación, PostgreSQL, API y sincronización en tiempo real. El proyecto se aloja en la Unión Europea (Irlanda) y aplica políticas RLS por usuario.

Menores

La aplicación no está dirigida a menores de 13 años. No permite comunicarse con otras personas, realizar compras ni ver publicidad. No solicita ubicación, contactos ni identificadores publicitarios. La cámara solo se activa tras una acción clara del usuario y su permiso de Android.

Conservación y eliminación

La cuenta y la colección sincronizada se conservan hasta que el usuario selecciona «Eliminar cuenta y datos» en Android o en la web. La eliminación borra el usuario, el perfil y la colección alojada, además de la copia local en Android. «Borrar colección» elimina las cantidades sin eliminar la cuenta. Las métricas técnicas de ML Kit se someten a las políticas de conservación de Google.

Seguridad y control

Las conexiones utilizan HTTPS y el tráfico sin cifrar está desactivado. PostgreSQL aplica reglas RLS para limitar cada consulta al usuario autenticado. El permiso de cámara puede retirarse desde los ajustes de Android. La colección puede exportarse, importarse o borrarse desde la aplicación.

Cambios y contacto

Esta política se actualizará si cambian las funciones o los servicios utilizados. Las consultas sobre privacidad pueden enviarse a jorgemegia96@gmail.com.

Lorcana Lector Privacy Policy

Effective date: August 20, 2026

Controller: Jorge Megía. Privacy contact: jorgemegia96@gmail.com.

Summary

Lorcana Lector requires an account to synchronize a collection between Android and the web. It contains no advertising and does not sell personal information. Camera images are processed in device memory and are not stored or transmitted by the app.

Data and permissions

  • Camera: used only while the scanner is open. Images and recognized text remain on the device.
  • Account: the email address, internal user identifier, and technical authentication data are processed to protect access.
  • Collection: cards, quantities, language, and finish are stored locally and in PostgreSQL for cross-device synchronization. Android automatic backup is disabled.
  • CSV files: the app reads or writes only a file expressly selected through Android's system picker.
  • Internet: used to download catalog data, images, and prices. Servers may receive technical connection data such as the IP address.

Third-party services

Google ML Kit processes camera input on-device and does not send images, recognized text, or results to Google. The SDK does collect app and device information, an installation identifier, usage events, errors, and performance metrics. Lorcast supplies public catalog metadata and images. Cardmarket/S3 supplies public product and price files. Supabase provides authentication, PostgreSQL, API, and real-time synchronization from its EU (Ireland) region.

Children

The app is not directed to children under 13. It has no user communication, purchases, or advertising, and does not request location, contacts, or advertising identifiers. Camera access requires a clear user action and Android permission.

Retention, deletion, and security

The account and synchronized collection remain until the user selects “Delete account and data” in Android or on the web. This deletes the hosted user, profile, and collection and the local Android copy. Network connections use HTTPS, cleartext traffic is disabled, and PostgreSQL RLS restricts records to the authenticated user.
